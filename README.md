These are large files and will put stress on your server, especially for old-gen players on PS4/Xbox One. Weather file for snow included and boosted animal event code for Hunters and PVE Players. The mod files were used on GROUND ZERO XBOX Servers
CHERNOMODWINTER.json has cool caves and pois players can explore and visit. Also, It Has Frozen Lakes and Rivers Inside the file. 
WinterDayZConsole-main was made by Don Sibley. Big Thank You To Don. Please Support His Work - https://github.com/DonSibleyGames/WinterDayZConsole
